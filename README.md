## 🔥 Featured Projects

### 🕵️ AI-Based Fake Review Detection System

An AI-powered system that detects whether customer reviews are fake or genuine using **RoBERTa** embeddings and a **Random Forest Classifier**. It helps improve the reliability of online review platforms by identifying misleading reviews. Built with **Python**, **Streamlit** for the interactive web interface, **Hugging Face Transformers** for NLP embeddings, and **Scikit-learn** for classification — includes text preprocessing and real-time prediction.
